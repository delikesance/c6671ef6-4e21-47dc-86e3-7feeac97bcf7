Bot Creator v2.10.0

New Features:
- A redesigned onboarding that matches the rest of the app: three clear steps, one main action per screen, and a step list on large screens
- When a bot cannot start, the app now explains why: hosting is busy, the platform is updating, the configuration was rejected (with the exact item), or free hosting time has to be earned from the mobile app
- A banner tells you when your latest changes are saved on the device but could not be synced, with the reason
- Switching a bot's engine lists the commands and workflows that cannot be carried over

Improvements:
- The AI Copilot writes in your bot's own language: JavaScript for a JavaScript bot, BDFD or blocks for a Dart bot, without asking
- Copilot answers and conversation summaries follow the language you write in
- A long Copilot answer cut by the length limit is kept instead of failing, and a failed reply gives your text back
- Continuing a conversation reopens the same continuation instead of creating duplicate chats that spend credits
- Copilot prompts are shorter for JavaScript bots, which saves credits

Bug Fixes:
- JavaScript bots: commands, events, schedules and webhooks created in Studio now run, and one malformed item no longer stops the whole bot from starting
- Command names that differ only by case, names over 32 characters, and webhooks without a path no longer break a JavaScript bot
- A failed start no longer uses up your bot quota
- A runner authentication hiccup during a platform update no longer marks your Discord token as invalid
- Running out of credits during a Copilot reply now shows the balance message instead of a raw code

Bot Creator v2.9.0

New Features:
- Meet the AI Copilot: a chat assistant that creates and edits your commands, and always asks for your approval before changing anything. Conversations are saved and previews show the script of a command before it is created
- AI credits: a wallet where 1 credit = 1,000 tokens, a credits page with the usage of each response, and a rewarded-ad roulette to earn more credits
- BDFD commands now run on a new native engine, and a built-in command sandbox lets you try a command (with options, context and permissions) before you publish it
- Visual blocks now run natively too, with many new blocks: moderation, roles, threads, channels, voice and music, polls, AutoMod, webhooks, emojis, images, components, modals and control flow
- Version history now uses cloud checkpoints, with previews of saved commands and workflows, and a way to delete versions
- Subscriptions can show offers published remotely by the server
- Bot Creator Studio, a web version of the editor, shares the app's screens, design and translations

Improvements:
- A flatter, calmer redesign of the home screen, the editor, the settings and the Copilot panels
- A top navigation bar on desktop, and a red disconnect button
- A live hosting countdown on the home bot cards, and the servers row on the bot card
- A simpler command editor: each option is edited on its own screen, grouped, with a live Discord preview, and lists of commands and workflows are simpler with a collapsible action palette and a Blueprint minimap
- The in-app documentation renders Discord structured blocks and dual-view previews natively, and respects safe areas on phones
- BDFD functions were aligned with the BDFD wiki
- Copilot answers are shorter and more reliable: compact sandbox results, clearer error codes, and a more stable mobile action flow

Bug Fixes:
- Importing or pulling a bot now updates its status and activities
- Starting the app no longer disturbs the bots that are running
- Commands keep their local and Discord identity when you save or restore them, and deleted items stay deleted
- Webhook URLs are now returned correctly
- Fixed layout overflows on narrow phones in the option editor and the Copilot
- Fixed article documentation that could stay out of date after a deployment

Bot Creator v2.3.0

New Features:
- Ready-Made Bots now fill in the variables their template declares: server-provided values (like your music server credentials) arrive pre-filled and locked, so a bot always starts with a valid configuration
- Your bot picks a working music server on its own, and only falls back to the ones you saved
- Ready-Made Bots appear in your home list, with readable logs and the ability to stop, restart or delete them
- The app now tells you when a new version is available, and lets you update from the store
- Rewarded ads pay more when you watch several in a day: up to 4 hours per ad for a bot, and the same scale for Ready-Made Bots

Improvements:
- Much lighter on the network: your status arrives over the live connection, one snapshot request replaces many, and polling slows down when you are not watching — better battery, fewer rate-limit errors
- Your hosting end date is now the real one sent by the server, instead of a misleading "permanent"
- Full translations for the new screens in German, Japanese, Portuguese and Turkish
- Google Drive reconnects silently in the background

Bug Fixes:
- A subscription is no longer erased locally when the server answers late: the store is re-checked before anything is cleared
- Fixed the container quota not blocking a launch in some cases
- A Ready-Made Bot no longer creates a phantom, unconfigured bot in your list
- Rewarded ads: an ad watched to the end now always counts, and an ad is no longer shown when the reward could not be validated

Bot Creator v2.1.11

New Features:
- Customize the app's appearance with new theme presets, per-mode accent colors, and a dedicated Settings card
- A single, unified navigation bar across the app and the bot editor, with a retractable sidebar on desktop
- Text Commands now support trigger aliases, so a single command can respond to several phrases
- Your bot cards now show the real icons of your Discord servers
- Hosted Apps are now "Ready-Made Bots": a redesigned, easier way to launch a bot in one click
- The code editor is back with full customization and a Rose Pine theme by default — code now highlights using your selected theme

Improvements:
- Faster home screen: servers are cached per session and images are cached on disk
- Smoother mobile and desktop layouts, with fixes for log overflow and wasted space on large screens
- Bundled all 5 Google Fonts, so text renders correctly and never downloads at runtime
- The embedded console now shows the same output as the logs page
- Better command editor blocks, blueprint layout, and clearer subscription savings
- In-app purchases now send your account ID for more reliable billing
- Google Drive reconnects silently in the background
- Full translations for Ready-Made Bots and the builder across all languages (German, Japanese, Portuguese, Turkish and more)

Bug Fixes:
- Fixed sync so your local bots and commands are preserved when pulling from the cloud
- Fixed duplicate "unknown" command names that could break bot sync
- Fixed $reaction, removeReaction, and role/permission functions in the transpiler, and improved signature hints
- Fixed hardcoded strings that were not translated, including in the image editor
- Improved accessibility: categories and palette colors are now readable in both light and dark themes
