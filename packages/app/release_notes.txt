Bot Creator v2.3.0

New Features:
- Ready-Made Bots now fill in the variables their template declares: server-provided values (like your music server credentials) arrive pre-filled and locked, so a bot always starts with a valid configuration
- Your bot picks a working music server on its own, and only falls back to the ones you saved
- Ready-Made Bots appear in your home list, with readable logs and the ability to stop, restart or delete them
- The app now tells you when a new version is available, and lets you update from the store
- Rewarded ads pay more when you watch several in a day: up to 4 hours per ad for a bot, and the same scale for Ready-Made Bots

Improvements:
- Much lighter on the network: your status arrives over the live connection, one snapshot request replaces many, and polling slows down when you are not watching — better battery, fewer rate-limit errors
- Your hosting end date is now the real one sent by the server, instead of a misleading "permanent"
- Full translations for the new screens in German, Japanese, Portuguese and Turkish
- Google Drive reconnects silently in the background

Bug Fixes:
- A subscription is no longer erased locally when the server answers late: the store is re-checked before anything is cleared
- Fixed the container quota not blocking a launch in some cases
- A Ready-Made Bot no longer creates a phantom, unconfigured bot in your list
- Rewarded ads: an ad watched to the end now always counts, and an ad is no longer shown when the reward could not be validated

Bot Creator v2.1.11

New Features:
- Customize the app's appearance with new theme presets, per-mode accent colors, and a dedicated Settings card
- A single, unified navigation bar across the app and the bot editor, with a retractable sidebar on desktop
- Text Commands now support trigger aliases, so a single command can respond to several phrases
- Your bot cards now show the real icons of your Discord servers
- Hosted Apps are now "Ready-Made Bots": a redesigned, easier way to launch a bot in one click
- The code editor is back with full customization and a Rose Pine theme by default — code now highlights using your selected theme

Improvements:
- Faster home screen: servers are cached per session and images are cached on disk
- Smoother mobile and desktop layouts, with fixes for log overflow and wasted space on large screens
- Bundled all 5 Google Fonts, so text renders correctly and never downloads at runtime
- The embedded console now shows the same output as the logs page
- Better command editor blocks, blueprint layout, and clearer subscription savings
- In-app purchases now send your account ID for more reliable billing
- Google Drive reconnects silently in the background
- Full translations for Ready-Made Bots and the builder across all languages (German, Japanese, Portuguese, Turkish and more)

Bug Fixes:
- Fixed sync so your local bots and commands are preserved when pulling from the cloud
- Fixed duplicate "unknown" command names that could break bot sync
- Fixed $reaction, removeReaction, and role/permission functions in the transpiler, and improved signature hints
- Fixed hardcoded strings that were not translated, including in the image editor
- Improved accessibility: categories and palette colors are now readable in both light and dark themes
